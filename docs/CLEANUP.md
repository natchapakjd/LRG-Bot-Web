# Cleanup Notes

## Removed Generated or Unused Artifacts

The following generated/deprecated artifacts were deleted from the working tree:

- Python `__pycache__/` directories under `app/` and `scripts/`.
- Python `__pycache__/` directories under `.venv/`; no installed package source files were removed.
- Tracked Python `.pyc` bytecode files under `app/**/__pycache__/`.
- Angular CLI cache under `frontend-angular/.angular/`.
- Local PyInstaller/Nuitka build output folders `build/` and `dist/`.
- `nuitka-crash-report.xml`, a generated compiler crash report.

These files are not source code. They are regenerated by Python, Angular, PyInstaller, or Nuitka as needed. The existing `.gitignore` already ignores most of them, but some generated files had been committed previously.

## Intentionally Kept

The following files/folders may look old or operational, but were kept because they are useful or not provably unused:

- `build.py`, `build_nuitka.py`, and `LRG-Bot.spec`: packaging tooling.
- `scripts/`: migration, backup, export, repair, and manual smoke-test utilities.
- `db/mysql/`: authoritative MySQL migration package.
- `database_schema.sql` and `mysql_schema.sql`: root-level schema references that may still be useful for migration history.
- `backups/mysql/`: existing SQL backup snapshots.
- `licenses.db`: local runtime/license data artifact.
- `workflow_templates/` and `templates/`: runtime image-matching assets.
- `.env` and `.venv`: local environment files, not source cleanup targets.

## Future Cleanup Candidates

Before deleting these, verify with the project owner or runtime database:

- Root diagnostic scripts such as `check_gacha_steps.py`, `check_json.py`, `check_ocr_region.py`, `fix_json.py`, `fix_ocr.py`, and `test_ocr.py`.
- Empty local folders like `accounts/` and `workflows/` if they are not used as operator workspaces.
- Root schema files if the team agrees `db/mysql/` is the only supported schema source.

- `build/`
- `dist/`
- `.venv/`
- `.env`
